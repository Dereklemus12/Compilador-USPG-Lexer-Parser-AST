Guion de presentación · 5 minutos

            
1
Presenta el objetivo. “Este proyecto procesa un programa escrito en un lenguaje sencillo: reconoce sus tokens, valida su estructura y tipos, genera TAC y lo ejecuta en una máquina virtual.”

            
2
Ejecuta el caso personal. En la terminal: python main.py pruebas/17_modulo_personal.txt. Señala el token `OP_MODULO`, el nodo `OpBinaria`, la tabla semántica, la instrucción `%` y la salida `1`.

            
3
Explica el control de flujo. Abre el caso `03_control.txt`; el TAC pone una etiqueta al inicio del ciclo, recalcula la condición y usa saltos para decidir si continúa.

            
4
Demuestra errores. Usa `04_error_falta_punto_coma.txt`, `16_error_modulo_booleano.txt` y `18_error_modulo_cero.txt` para enseñar detección en Parser, semántica y VM.

            
5
Concluye con pruebas. Ejecuta python -m unittest discover -s pruebas -p "test_*.py" -v; el resultado documentado es 58 tests correctos.
